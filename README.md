# ✈️ Airlines Delay Dashboard

## 📌 Overview
This project analyzes flight delays in the United States.  
The data was cleaned and transformed using Python and Jupyter Notebook, then visualized using Power BI to discover trends and patterns in flight delays.

## 🧹 Data Cleaning
- Removed missing and incorrect values.
- Fixed column errors.
- Created fact and dimension tables:  
  - `FactFlights`  
  - `DimRoute`  
  - `DimDate`  
  - `DimAirCraft`

---

## 📈 Power BI Measures
- **Total Distance**
- **Total Flights**
- **Average Delay**
- **Average Distance**
- **Total Delay Minutes**

---

## 📉 Dashboard Visuals
- **Card Visuals:** KPIs for Total Distance, Average Delay, Total Flights, etc.  
- **Line Chart:** Average Delay by Month.  
- **Bar Chart:** Total Delay by Airline.  
- **Bar Chart:** Average Delay by Route.  
- **Tree Map:** Total Flights by Origin.  
- **Top N Chart:** Top 10 Origins by Flights.
